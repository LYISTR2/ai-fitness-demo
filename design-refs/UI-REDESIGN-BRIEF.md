# UI 重构 Brief（用户指定 · 2026-09-06）

## 定位
力量/综合健身向：清爽 + 运动感。参考：训练计划＋动作指导＋训练记录类 App（Hevy 记录流、NTC 内容组织）。

## 视觉 Token
| 用途 | 值 |
| --- | --- |
| 日常页背景 | `#F7F8FA` |
| 训练页背景 | `#14171B`（石墨黑） |
| 卡片 | 白卡；圆角 20–24；细边框 + 轻阴影，不满屏浮起 |
| 强调色 | 电光绿 `#C8F750`（开始按钮、进度、选中）；配深色文字 |
| 正文/数字 | 高对比深色或训练页浅色；**禁止全文涂绿** |
| 完成态 | 勾选或文字 + 颜色（不单靠颜色） |
| 字体 | 标题偏粗；核心数字大、单位小；避免整页粗体 |
| 图标 | 统一线性图标；动作图/演示统一风格，不混插画 |

参考图：`design-refs/ref-*.jfif`（浅色薄荷 / 深色电光绿 / 浅色仪表盘 / 浅色训练）。以用户文案为准：日常浅、训练深；强调色取电光绿，不取鼠尾草绿瑜伽风。

## 信息架构
1. **首页**：只回答「今天练什么」。上：日期+本周情况；中：醒目「今日训练」主卡（课名、动作数、预计时长、开始训练）；下：「继续上次」+ 短进度。第一屏不塞步数/饮水/热量/睡眠/体重/排行。
2. **训练页**：像好用记录表。上：动作名+演示；中：组/重量/次数 + 上次记录；底固定大按钮「完成本组」。参考 Hevy：组次、上次数值、自动休息、进度。
3. **动作指导**：独立；短视频/循环演示 + 暂停重播 + 要点。不上 3D。

## 动效（六种，服务操作反馈）
| 场景 | 要点 | 时长建议 |
| --- | --- | --- |
| 打开计划 | 卡片展开延续，非整屏飞入 | 220–320ms |
| 完成本组 | 行勾选+底色轻变+进度；可轻触感 | 120–180ms；不弹大窗 |
| 组间休息 | 环形进度连续减，中间大号数字固定 | 不上下翻滚 |
| 切换动作 | 当前轻移出、下一接续，底按钮不乱跑 | 方向一致 |
| 趋势图 | 首次绘出；周月切换平滑；返回不重演 | — |
| 完成整次 | 环闭合→标记→总结 | 600–900ms；仅破纪录时少量庆祝 |

核心链路优先：**完成本组 → 轻反馈 → 休息计时 → 结束提醒 → 下一组就绪**。记录立即生效，不等动画。尊重减少动态效果；提醒不止靠动画。

## 细节
- 训练按钮大且位置固定；触控 ≥48dp；半透明最多点缀导航/弹层，关键区实底。
- 不每组撒彩带。
